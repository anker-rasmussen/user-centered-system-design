# FigJam stickies — copy-paste source for the affinity diagram

How to use:

1. Open a blank FigJam board.
2. Drop five large bold text labels across the top: **T1**, **T2**,
   **T3**, **T4**, **T5** (or keep the Greek-letter names α–ε if you
   prefer). Add a sixth label "**Did not cluster**" off to one side.
3. Press **`S`** to grab the sticky-note tool.
4. For each cluster below, **select all the lines in the code block**,
   copy, then click under the matching column header in FigJam and
   paste — FigJam creates **one sticky per line**. (Use the keyboard
   shortcut **`Cmd/Ctrl+V`** with the sticky tool active.)
5. Drag stickies around inside the column to taste; FigJam will
   colour them automatically. Optionally recolour each column for
   visual contrast.
6. Frame everything (`F`), name the frame "Affinity Diagram —
   Phase 3 Theme Map", export as PDF, drop the PDF into
   `Coursework/part-2/figures/` and `\includepdf` it from
   Appendix~F (`app:analysis`) in `pt2.tex`.

Each sticky preserves the participant tag (P1–P4) so the affinity
diagram stays evidence-traceable.

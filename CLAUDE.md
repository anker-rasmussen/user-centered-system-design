# CLAUDE.md — User-Centred System Design

## GenAI Attribution (Required)

Whenever you make changes to any coursework file in this repo, you **must** add a corresponding entry to the GenAI Usage Log appendix in the relevant part's `.tex` file (e.g. `Coursework/part-1/pt1.tex`). Each entry must include:

- **Date** of the interaction
- **Tool** used (model name and interface)
- **Prompt/Input** — the user's prompt, verbatim or summarised
- **Output & Use** — what was generated and how it was used

Do not skip this step. The coursework brief requires all GenAI use to be declared.
